# Skills

Skills are reusable workflows that help Sky-Agent perform repeated tasks consistently.

## What skills are for

Use skills when a task benefits from a reusable process, a focused set of instructions, or deterministic supporting material.

## What this guide should cover

- built-in skills and their purpose
- how custom skills are structured
- when to use a skill instead of general agent prompting
- how skill overrides and references should work

## Design goals

A good skill should be narrow, explicit, and easy to load only when needed.
