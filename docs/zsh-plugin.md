# ZSH Plugin

SkyBolt currently includes ZSH integration through `sky setup` and `sky zsh` commands.

Implemented shell functionality includes:

- Installing/updating shell integration from the CLI.
- Shell completion support tied to the current CLI command structure.
- Right-prompt/status integrations backed by local session and usage data.
- Shell diagnostics through `sky doctor`.

Some plugin internals still use legacy Forge filenames and function names.
