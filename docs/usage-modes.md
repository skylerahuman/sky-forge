# Usage Modes

Sky-Agent supports three ways to work:

## Interactive mode

Use this when you want the agent to drive a longer task while you guide direction.

## One-shot mode

Use this for quick prompts, scripts, and command-line automation.

## ZSH plugin mode

Use this for rapid iteration from your shell with `:`-prefixed commands.

See the dedicated [ZSH Plugin](zsh-plugin.md) guide for the full reference.
