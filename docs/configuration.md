# Configuration

SkyBolt currently uses the existing Forge configuration model. Public branding is `SkyBolt`, but config types, schema names, and some file paths still use `forge` for compatibility.

Current configuration areas include:

- Active agent, model, and provider settings.
- Provider authentication and service URLs.
- Retry and update behavior.
- HTTP proxy, TLS, timeout, and keep-alive settings.
- Tool timeout and output limits.
- Auto dump and debug request settings.
- Shell prompt cost display settings.
- MCP server configuration.
- Permission and policy behavior.

The generated schema is currently `forge.schema.json`.
